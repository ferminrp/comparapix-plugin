# ComparaPix plugin

Cursor / Grok Bot plugin for [comparapix.ar](https://comparapix.ar).

Remote MCP (no auth): `https://api.comparapix.ar/mcp`

Tools: `best_rate`, `calculate_pix`, `get_quotes`.

Better rate = more BRL per peso or dollar (lowest `buy`). Always return the provider `url` from the API (affiliate link).
